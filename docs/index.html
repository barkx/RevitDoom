The real game, inside Revit

RevitDoom adds a DoomRevit ▸ Games panel to the ribbon with one button. Click DOOM and play.

Engine

Managed Doom

A faithful C# port of the original DOOM engine, compiled for .NET 8, the runtime Revit 2025+ uses.

Timing

Original 35 Hz

The game runs at the original 35 updates per second, drawn with interpolation at 640×400 and shown at 4:3.

Sound

Positional stereo

Sound effects play through the Windows waveOut API. If audio can't start, the game keeps running without it.

Safe

Can't crash Revit

Pure managed code. If the engine fails you get a message in the console; Revit keeps working.

WADs

Freedoom included

Plays free Freedoom out of the box. Drop in DOOM.WAD or DOOM2.WAD, or Shift+Click to pick any WAD; your choice is remembered.

Saves

Savegames & cheats

Savegames and settings live in %APPDATA%\RevitDoom. iddqd and idkfa work.

✔
Your model is left untouched. The game runs in its own window inside Revit and never creates or changes elements.

Install in three steps

You need pyRevit. If you don't have it, install it from pyRevitLabs/pyRevit and start Revit once.

  1. Get the files

    Clone the repository, or use Code ▸ Download ZIP on GitHub and extract it (right-click the ZIP ▸ Properties ▸ Unblock first).

    cd C:\RevitExtensions git clone https://github.com/barkx/RevitDoom.git

  2. Add it to pyRevit

    In Revit: pyRevit ▸ Settings ▸ Custom Extension Directories. Add the folder that contains RevitDoom.extension, for example C:\RevitExtensions\RevitDoom.

  3. Reload and play

    Click Save Settings and Reload. Open the DoomRevit tab and click DOOM.
